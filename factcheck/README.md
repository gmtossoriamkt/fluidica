# Фактчекинги редактора

Фактчекинг статьи из `content-plan.csv` кладётся сюда, имя файла - номер статьи: `42.md`.
Агент учитывает замечания, рекомендованный заголовок и структуру, но сам фактчекинг -
вторичный источник: его утверждения тоже проверяются по первоисточникам.

Папка не публикуется на сайте (исключена в `_config.yml`).
