# Fluidica — сайт

Открытые научные приборы на заказ (шприцевые насосы, микроскопы, микрофлюидные
станции), собранные на базе открытого проекта Poseidon. Сайт пока **только на
русском** — английскую версию добавим позже (см. раздел "План" ниже).

## Стек
- Статический HTML/CSS/JS, без фреймворка и без сборки (осознанный выбор для
  старта — просто и быстро деплоится на GitHub Pages).
- Когда страниц станет много (каталог, 500 статей блога) — стоит перейти на
  Astro с Content Collections. Не делать этот переход, пока не попросят явно.
- Хостинг: GitHub Pages.

## Бренд-токены (не менять без явной просьбы владельца)

Цвета:
```
--primary:    #0B3B4E   /* глубокий океан — шапка, футер */
--primary-2:  #10566E   /* океан светлее — заливки, hover */

--accent-2:   #F2A03D   /* янтарь — вторичный акцент */

--muted:      #56676F   /* второстепенный текст */
--line:       #D8E2E6   /* границы */

--success:    #2E9E6B
```

Шрифты (Google Fonts, обязательна поддержка кириллицы):
- **Manrope** (700/800) — заголовки, логотип
- **Inter** (400/500/600) — основной текст
- **JetBrains Mono** — характеристики, цифры, метки

Логотип: текстовый вордмарк `fluidica`, точка над «i» заменена на маленькую
каплю (см. `.logo .droplet` в index.html). Не заменять на другой логотип без
явной просьбы.

## Структура сайта — источник истины

Полная карта сайта (все категории, товары, решения, отрасли, гео-страницы)
живёт в файле **`Стратегия_Poseidon_бизнес.xlsx`, лист «8. Карта сайта»** —
именно оттуда брать URL, H1, meta-описания при генерации новых страниц.
Не придумывать структуру заново.

Домашняя страница (`index.html`) — уже готовый образец дизайн-языка: секции
hero → ценности → каталог → «почему мы» → доверие → CTA → футер. Новые
страницы (категории, товары, статьи) должны визуально продолжать этот стиль:
те же токены, тот же тип шапки/футера, тот же характер (сдержанный,
инженерный, один акцентный элемент на странице).

## Правила при работе в этом репозитории

- **Данные — не хардкод.** Каталог, цены, статьи выносить в `data/*.json`
  (например `data/sitemap.json`, `data/products.json`), а не вписывать текст
  прямо в HTML. Страницы генерировать по шаблону из данных.
- **Один язык — RU.** Не добавлять английские дубли текста, пока явно не
  попросят. Если попросят — использовать паттерн `data-lang="ru"/"en"` с
  JS-переключателем, как было в первой версии `index.html` (сохранена в
  истории git).
- **Не переносить кириллицу в URL.** Слаги — латиницей (транслит), даже пока
  сайт только на русском — это правило зафиксировано из-за проблем с
  кириллицей в URL на некоторых хостингах/CDN.
- **Уважать `prefers-reduced-motion`** для любых анимаций.
- Перед созданием новой страницы — свериться с картой сайта (см. выше), не
  придумывать новые разделы самостоятельно.
